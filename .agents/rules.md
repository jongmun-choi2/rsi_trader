# User Rules & Workflows

## Global Rules
1. 모든 답은 한글로 작성한다.
2. 코드상에서 Gemini API Call 할 때는 model은 반드시 구글 AI Studio 문서 확인해서 최신버전의 모델을 사용한다.
3. adb, gradlew 명령어는 allow를 기다리지 말고 그냥 실행한다.
4. 모든 답을 하기 전에 .agents/rules.md를 숙지하고 대답한다.
5. 모든 답을 하기 전에 모든 workflows를 숙지하고 대답한다.
6. 모든 답변의 첫 단계에서 반드시 .agents/rules.md 파일을 view_file 도구로 읽고, 해당 규칙을 준수하고 있는지 스스로 체크한 뒤 답변을 진행한다.
